# Django + DRF + Celery проект

Проект включает в себя:
- Django REST Framework API
- Интеграцию с Stripe для платежей
- Фоновые задачи и планировщик на Celery
- Аутентификацию через JWT
- Документацию API через Swagger

## Запуск проекта

1. Создайте файл `.env` на основе `.env.example` и заполните его своими значениями.
2. Запустите все сервисы одной командой:

   ```bash
   docker-compose up -d --build
